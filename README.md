**Control your Nissan electric vehicle directly from Homey.**

This app integrates [Nissan's connected services (EV & ICE) into Homey](https://homey.app/a/com.nissan.connect), allowing you to monitor battery status, control climate, and automate charging flows.

## 📱 Supported Vehicles
* **Nissan Leaf** (ZE1 and newer models)
* **Nissan Ariya** (unverified)
* **Nissan Qashqai** (e-Power, unverified)
* *And other models using the Nissan Connect Services app.*

## 🐛 Issue Tracking
**This repository is a public issue tracker for the Nissan Connect Homey app.**
The source code for this application is closed-source/private, but we use this repository to track bugs, feature requests, and public releases.

### How to report a bug
1.  Check the [existing issues](https://github.com/fridtjofsen/homey-nissan-connect/issues) to see if your problem has already been reported.
2.  Open a **[New Issue](https://github.com/fridtjofsen/homey-nissan-connect/issues/new/choose)**.
3.  Please include:
    * **Car Model:** (e.g., Nissan Leaf 2019)
    * **App Version:** (e.g., v0.4.0)
    * **Diagnostic Report ID:** (If applicable, send via Homey app settings)

## 🚀 Features
* **Battery Monitoring:** Trigger flows when battery drops below/rises above specific %
* **Climate Control:** Start/Stop AC remotely.
* **Charging Control:** Start/Stop charging (on supported chargers/models).
* **Location:** See vehicle location (Latitude/Longitude).
* **Tire Pressure:** Monitor individual tire pressures (TPMS).
